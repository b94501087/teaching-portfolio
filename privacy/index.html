蒐集哪些資料What we collect

  • 諮詢表單：您在諮詢頁填寫的姓名、Email、需求簡述，以及所選方案、幣種與支付偏好。按下「索取付款指示」後，本站不會把這些內容傳到伺服器，而是在您的裝置上開啟一封 Email 草稿；只有您自行寄出，我們才會收到。Consulting form: the name, email, short description, plan, currency and payment preference you enter on the consulting page. The site does not send these to a server. It opens an email draft on your device, and we receive it only if you send it.
  • Email 往來與付款：您寄來的信件與附件（例如作品集檔案），以及付款、入帳與退費紀錄。線上收款尚未開通。Email and payments: the emails and attachments you send (for example portfolio files), and payment, receipt and refund records. Online payment is not yet available.
  • 訂閱：在部落格訂閱新文章時填寫的 Email 與介面語言，以及訂閱與更新的時間，存放於 Cloudflare D1 資料庫。Subscriptions: the email address and interface language you give when subscribing to new blog posts, and when you subscribed and last updated, stored in a Cloudflare D1 database.
  • 閱讀數、按讚與收藏：瀏覽文章時，您的瀏覽器會產生一組隨機識別碼，連同文章代稱送到本站的計數服務（Cloudflare Workers）。伺服器在 Cloudflare D1 為每一筆閱讀、按讚或收藏保存：經雜湊處理的識別碼、文章代稱、類型（閱讀、按讚或收藏）、狀態與時間，另保存每篇文章的總數。閱讀請求沒有帶識別碼時，改以經雜湊處理的 IP 位址作為識別。頁面只顯示總數。Reads, likes and bookmarks: when you read a post, your browser creates a random ID and sends it with the post name to the site's counting service (Cloudflare Workers). For each read, like or bookmark, the server stores in Cloudflare D1 a hashed ID, the post name, the type (read, like or bookmark), its state and the time, plus each post's totals. If a read arrives without an ID, a hashed IP address is used as the identifier instead. Pages show totals only.
  • 防濫用：計數與訂閱服務會保存您的 IP 位址加鹽雜湊值，以及請求類別、次數與計算起始時間，用來限制短時間內的大量請求，不保存原始 IP。Abuse prevention: the counting and subscription service stores a salted hash of your IP address with the request type, a count and the start of the counting window, to rate-limit requests. The raw IP address is not stored.
  • 瀏覽器本機資料：語言選擇（localStorage「lang」，在網址帶 ?lang= 或按語言切換鈕時寫入）；以及 localStorage「yct-engage」，內含隨機識別碼、各篇文章最後一次送出閱讀的時間、按讚清單、收藏清單（每筆含文章代稱、網址、日期、標題與收藏時間），以及按讚、收藏是否已同步到伺服器的紀錄。這些只存在您的瀏覽器，可隨時清除。Browser storage: your language choice (localStorage "lang", written when the address has ?lang= or you press a language button); and localStorage "yct-engage", which holds the random ID, the last time a read was sent for each post, your likes, your bookmarks (each with the post name, address, date, title and time saved), and whether each like and bookmark has been synced to the server. These stay in your browser, and you can clear them at any time.
  • 除下方列出的 Cloudflare Web Analytics 外，本站沒有使用 Google Analytics 等其他分析或廣告追蹤工具；本站程式碼也不設定 Cookie。Apart from Cloudflare Web Analytics, listed below, the site uses no other analytics or advertising trackers such as Google Analytics, and its own code sets no cookies.
